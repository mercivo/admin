# Google Cloud 成本与存储配置基线

> 核查日期：2026-10-11，项目：`mercivo-admin`，区域：`asia-east1`。

## 存储策略

- 运行时只使用 `mercivo-images-753805870951` 一个 Standard 单区域桶。
- 本地开发上传到 `local/`，Cloud Run 上传到 `production/`。
- 不允许回退到容器或主机本地目录；缺少 GCS 配置或凭据时直接返回存储服务不可用。
- `mercivo-private-753805870951` 目前为空桶，现行代码不读取它。空桶不产生对象存储费，完成上传验收后再删除。
- `local/` 适合设置 30 天自动删除；`production/` 不设无条件删除规则。

Cloud Storage Standard 在 `asia-east1` 的存储单价约为 **US$0.02/GiB/月**。预算示例：

| 对象数据量 | 月存储费（不含请求和外网流量） |
| --- | ---: |
| 10 GiB | US$0.20 |
| 50 GiB | US$1.00 |
| 100 GiB | US$2.00 |

公网图片下载才是存储的主要变动费用，亚洲目的地低用量档一般按约 **US$0.12/GiB** 计算。小流量阶段保持 Standard，不将活跃商品图片转为 Nearline/Coldline，以避免取回费和最低保存期费用。

## Cloud SQL 现状与预算

核查时 `mercivo-mysql` 已停止，原规格为 4 vCPU / 16 GB / 100 GB SSD，单可用区，开启自动备份与 PITR。本月截至 10 月 11 日的实际费用为 **US$7.82**，结算预测整月 **US$24.68**，均来自 Cloud SQL：

- 100 GB SSD：本月已产生 US$5.44，按当前速率约 **US$17/月**。
- 公网 IP 保留：本月已产生 US$2.38，约 **US$7.30/月**。
- 实例停止时不收取 vCPU/内存运行费，但存储和 IP 仍计费。

现有实例可就地下调到的最低规格是 **1 vCPU / 3.75 GB**；无法就地改为共享核心，也无法缩小已分配的 100 GB 磁盘。

### 推荐分阶段方案

1. 开发/验收期：保持 Cloud SQL 停止，本地 Docker MySQL 承载开发数据；云端固定费用约 US$24.30/月。
2. 首次上线：将现有实例降为 1 vCPU / 3.75 GB，保持单区域、自动备份和 PITR，Cloud Run 保持 `min-instances=0` / `max-instances=1`。
3. 进一步降低固定费用：在确认数据迁移窗口后，新建 10 GB 最小规格实例，完成备份、迁移、校验和切换后再删除旧实例。这是降低 100 GB 固定存储费的唯一可靠方式，不在未验证数据的情况下直接删库重建。

Cloud Run 当前用量位于免费额内，本月资源原价 US$0.16，抵扣后为 US$0.00。

## 成本控制线

- 账单预算建议设为 **US$30/月**，在 50% / 90% / 100% 触发邮件。
- 上线后前两周每周检查 Cloud SQL CPU、内存、连接数和磁盘增长，只在指标长期紧张时扩容。
- 暂不购买 Cloud SQL 承诺使用折扣；低流量阶段保留随时降配或迁移的灵活性更重要。
